# Asset provenance

Audit date: 2026-07-24.

The public source tree contains no tracked binary images, fonts, PDFs,
PowerPoint files, videos, or customer reference decks. Example and stress
slides are constructed from editable HTML text, CSS colors and shapes, native
table/chart data, and small inline SVG paths authored as repository fixtures.
They do not load external image URLs or require third-party media downloads.

This means there are currently no redistributable media assets requiring a
separate attribution table. Before adding any image, logo, font, PDF, deck, or
video, record its repository path, original source URL or author, license,
modifications, and redistribution permission in this file.
